Employee Time Clock

Controlled clock-in/out records, employee verification, correction requests, and audit-ready time history.

Permission model: Employees clock only their own account. Managers cannot view other employees' exact clock-in/out records and cannot edit time records. Only Super Admin can approve or decline corrections and make an authorized correction.
Failed clock-in/out escalation: If an employee cannot complete their own security verification, the employee must notify their manager. The manager must notify Super Admin before proceeding with normal managerial duties. The manager cannot clock the employee in/out, obtain the employee's security answer, or bypass the verification process. Manager access to the affected work workflow remains restricted until Super Admin resolves the clock issue.

Employee Verification

Clock-in/out will require the employee to confirm: “Are you the employee clocking in/out?” A Yes response triggers the employee's private security question. Failed verification creates no punch and starts the manager → Super Admin escalation workflow.

Super Admin Clock Override

Super Admin can securely perform an authorized employee clock-in/out override after the manager reports a failed employee verification. The system records the override, exact time, reason, manager notification, and employee notification. Employee security answers are never displayed as a normal password or shared with managers.

Correction workflow: Employee submits a correction request with the reason and requested times. Manager may review and notify Super Admin, but cannot approve, decline, or edit the timesheet. Only Super Admin can make the final decision. Original punches remain in the audit history.
